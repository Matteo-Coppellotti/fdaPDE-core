# Example code for G100@Cineca
In this directory an example code using the MUMPS wrapper can be found. With it there are an example of a bash script for compilation and a Slurm file for submitting a batch job. Here are some instructions to follow to configure the latter correctly. Spack environment setup is assumed (according to the project report installation guide).

## Compilation
To compile the example code it is sufficient to run the script `compile_code.sh`:
```
./compile_code.sh
```
This will generate a `build` directory.

## Submitting a batch job
To configure the Slurm correctly it is sufficient to change the variable `WORKING_DIR` to the path of the `build` directory generated by the compilation script. Additionaly it is possible to change the #SLURM variables following the documentation found [here](https://wiki.u-gov.it/confluence/display/SCAIUS/6%3A+Scheduler+and+Job+Submission).

To submit the bath job use:
```
sbatch example_job.slurm
```
This will assign a job ID. It is possible to check the batch job status by using:
```
squeue --job <job ID>
```
